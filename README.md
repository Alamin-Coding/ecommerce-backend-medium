# Installation in 3 Steps

 **Clone and install**
```bash
   git clone https://github.com/Alamin-Coding/ecommerce-backend-medium.git
   cd ecommerce-backend-medium
   npm install


## You just need to:

1. Clone
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Update credentials
5. Run `npm run dev`

That's it! Keep it simple. 🎯
